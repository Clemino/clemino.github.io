Associer le téléphone

Scannez avec l'appareil photo du téléphone. Le QR code se masque dès qu'un appareil est associé ; les autres sont ensuite refusés.

Efface le texte sur le téléphone et génère un nouveau QR code. Fermer cet onglet termine aussi la session.

Comment c'est sécurisé ?
  • Le texte passe directement du PC au téléphone (WebRTC), sans être stocké nulle part.
  • Il est chiffré de bout en bout (AES-256-GCM) avec une clé qui n'existe que dans le QR code : elle n'est jamais envoyée à un serveur.
  • Le relais de mise en relation (PeerJS) ne voit qu'un identifiant aléatoire, jamais le contenu.
  • Une nouvelle clé est créée à chaque session ; rien n'est enregistré sur le PC.
  • Aucun script externe, aucun traceur ; la correction orthographique et la traduction automatique sont désactivées.
