Comment lire le parcours
  • Chaque étape commence par un téléporteur. Ouvre la carte, téléporte-toi, puis suis les objets dans l'ordre.
  • Pour chaque objet : la flèche et la distance partent du point précédent (le téléporteur pour le premier). Le haut de l'écran est le nord.
  • Les coordonnées sont celles affichées sur la carte du jeu (X, Y). Pose un marqueur dessus pour te guider.
  • Les distances sont à vol d'oiseau : le parcours est pensé avec une monture volante.
  • Les noms des téléporteurs sont les noms français officiels du jeu.
  • Si un téléporteur n'est pas encore débloqué, vole jusqu'à lui depuis l'étape précédente : il se débloque en passant.
  • L'Arbre-Monde est gardé pour la fin, car c'est la zone la plus difficile. Elle a sa propre carte dans le jeu.
  • Positions extraites des fichiers du jeu par le projet PalDex : 577 objets. op.gg en compte 521, il lui manque notamment les 30 statues de Cattiva.
