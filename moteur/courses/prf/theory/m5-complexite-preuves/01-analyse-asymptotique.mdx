## Mesurer ce qui grandit

La complexite decrit l'evolution du cout quand la taille `n` augmente. On ignore les constantes pour comparer les ordres de grandeur.

## O, Omega, Theta

- `O(f(n))` : borne superieure asymptotique.
- `Omega(f(n))` : borne inferieure asymptotique.
- `Theta(f(n))` : encadrement serre.

```text
3n^2 + 10n + 7 est Theta(n^2)
```

## Cas d'analyse

Le pire cas donne une garantie. Le meilleur cas est souvent peu informatif. Le cas moyen exige une hypothese probabiliste.

## Exemples du cours

Recherche sequentielle : pire cas lineaire. Recherche dichotomique sur structure triee a acces indexe : logarithmique. Produit matriciel classique : cubique.
